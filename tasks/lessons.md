# Lessons

- **2026-07-06 — "look like X" ≠ "behave like X".** Daniel shared shadcn docs screenshots wanting the *visual* style (flush header, borderless sidebar, clean sizing) but I also changed the sidebar *behavior* (hover-expand → always-open) and he had to revert it. When reference screenshots come in, separate the ask into look vs. behavior and confirm behavior changes explicitly — existing interactions (hover-expand sidebar, hidden desktop toggle) are deliberate choices, not accidents.
